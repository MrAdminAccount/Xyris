# Xyris

**A multipurpose Discord bot built with Discord.js v14 and MongoDB.**

Xyris is a verified multipurpose Discord bot designed to provide a range of features for Discord communities, serving **200+ servers and 50,000 users**.

## Features

Xyris organises its functionality into several categories:

- **Fun** — Entertainment and community engagement.
- **Information** — Informational commands and utilities.
- **Moderation** — Tools for managing Discord communities.
- **Other** — Additional bot functionality.
- **Utility** — General-purpose server utilities.

*Feature availability depends on the commands implemented in the project.*

## Tech Stack

- **JavaScript**
- **Discord.js v14**
- **MongoDB**
